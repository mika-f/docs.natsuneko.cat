title: Fleet

Fleet とは、24時間で自動的に削除される縦型投稿のことです。 X (Twitter) にかつてあった Fleet、 Instagram にある Story と同じような投稿形式です。
Fleet は、現時点ではフォロワーにのみ表示されます。

![](https://images.natsuneko.com/b4feb0e617bfa93b84c755da922bcf0157974e1a76425fc6038dd5e73f02f9af.png)

## Fleet の作成

Fleet の作成には、次のような専用のエディターを使って作成します。

![](https://images.natsuneko.com/5319eab058492ecabe51bef2268cc04bc96e1f2d5504d24a022c9e61f9de5322.png)

最低1枚のベース写真と、背景色、任意でテキストやスタンプを追加することができます。

### 背景色

背景色を選ぶことが出来ます。背景色は一番下のレイヤーとして使われ、規定のものから、もしくは一番右のカラーピッカーから選ぶことができます。

### NSFW としてマーク

Fleet を NSFW としてマークすることができます。 NSFW としてマークされた Fleet は、ユーザーの閲覧設定で ON にしない限りは表示されません。

### 画像

1枚の画像をベースとして選ぶことができます。画像は、位置、任意のサイズ、回転を変更することができ、自由に配置することができます。
位置は画像をドラッグすることで変更することが出来ます。

### テキスト

テキストを追加することができます。任意の短いテキスト、フォント、サイズ、スタイル、位置、回転、色を変更することができ、自由に配置することができます。
文字色、背景色ともに、カラーピッカーから選ぶことができます。
位置はテキストをドラッグすることで変更することが出来ます。
最大10個までのテキストを追加することができます。

### ステッカー

Catalyst 標準で提供しているリアクションの中から、ステッカーを選んで配置することができます。ステッカーは、位置、任意のサイズ、回転を変更することができ、自由に配置することができます。
位置はステッカーをドラッグすることで変更することが出来ます。
最大10個までのステッカーを追加することができます。

## Fleet の削除

Fleet の削除は、Fleet の作成者のみが行うことができます。削除は Fleet を開いて、右上にあるゴミ箱アイコンから行うことができます。

## Fleet の閲覧

Fleet は、自身と作成者のフォロワーにのみ表示されます。 Fleet を閲覧するには、ホーム画面の上部にある Fleet のアイコンをタップすることで、作成者の Fleet を閲覧することができます。
通常、時間経過によって自動再生されます。複数枚の Fleet がある場合は、タップすることで、もしくは時間経過で自動的に次の Fleet に切り替わります。

## リアクションをする

Fleet にはリアクションを最大1つまで行うことが出来ます。行ったリアクションは通常の投稿のリアクションと同様に本人にのみ通知されます。

## リアクションを確認する

Fleet の作成者は、Fleet に対して行われたリアクションを確認することができます。 Fleet を開いて、右上にあるハートアイコンをタップすることで、リアクションの一覧を確認することができます。
