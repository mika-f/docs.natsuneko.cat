---
title: カスタムリアクション
---

カスタムリアクションは、[リアクション](./10-reaction.md)の一種で、ユーザーが独自に作成したリアクションです。カスタムリアクションを作成することで、オリジナルのリアクションを投稿に付与することができます。
カスタムリアクションはユーザー自身が作成した画像を使用することができ、投稿に対してより個性的なリアクションを行うことができます。

例：https://catalyst.natsuneko.com/status/886e518e-2861-4fb7-9df7-d68a7db97529

## カスタムリアクションの登録

カスタムリアクションは[サポータープランの特典](./80-supporter.md)として、サポータープラン (100円以上のもの) に加入しているユーザーのみが作成することができます。
それぞれ、プランに応じて登録できる枠数が異なります：

| プラン           | 枠数  |
| ---------------- | :---: |
| Tier #0 (100円)  | 10枠  |
| Tier #1 (500円)  | 20枠  |
| Tier #2 (1000円) | 30枠  |
| Tier #3 (1500円) | 50枠  |
| Tier #4 (2000円) | 75枠  |
| Tier #5 (5000円) | 100枠 |

カスタムリアクションの登録は Catalyst の[「設定」→「カスタムリアクション」](https://catalyst.natsuneko.com/settings/custom-reactions)から行うことができます。
カスタムリアクションでは、 128px x 128px の最大 1MB までの正方形の画像をアップロードすることができます。アップロードした画像は、 Catalyst 上で自動的に 32px x 32px に縮小され、リアクションとして使用されます。
登録するには、それぞれ次のフィールドを埋める必要があります：

| フィールド     | 説明                                                                                                                                 |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| ショートコード | 投稿に付与する際に使用するショートコードです。半角英数字で、他のリアクションと重複しないようにしてください。                         |
| 表示名         | リアクションの表示名です。投稿に付与された際に、リアクションの上に表示されます。                                                     |
| 公開範囲       | カスタムリアクションの公開範囲です。公開範囲を「本人のみ」に設定した場合、他のユーザーはそのリアクションを使用することができません。 |

## カスタムリアクションの公開範囲

カスタムリアクションには公開範囲を設定できます。それぞれ、次のような公開範囲があります：

| 公開範囲       | 説明                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| 本人のみ       | 自分自身のみが使用できるカスタムリアクションです。他のユーザーは使用することができません。                     |
| フォロワーのみ | 自分のフォロワーのみが使用できるカスタムリアクションです。フォロワー以外のユーザーは使用することができません。 |
| 全員           | 誰でも使用できるカスタムリアクションです。すべてのユーザーが使用することができます。                           |

また、別途制限として、**公開範囲にかかわらず、最初の1つめのリアクションは登録者本人が行う必要があります**。

## カスタムリアクションの削除

カスタムリアクションの削除は、Catalyst の[「設定」→「カスタムリアクション」](https://catalyst.natsuneko.com/settings/custom-reactions)から行うことができます。削除したカスタムリアクションは元に戻すことができませんので、注意してください。
