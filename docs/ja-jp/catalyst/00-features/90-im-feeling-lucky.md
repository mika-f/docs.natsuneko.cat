---
title: I'm Feeling Lucky
---

I'm Feeling Lucky とは、 Catalyst 上で、ユーザーが投稿したすべてのコンテンツの中から、ランダムに1つの投稿を表示する機能です。ユーザーは、 I'm Feeling Lucky を使うことで、 Catalyst 上で投稿されたコンテンツをランダムに閲覧することができます。

https://catalyst.natsuneko.com/lucky

[X (Twitter)](https://x.com/_CatalystVR_) および [Misskey](https://misskey.resonite.love/@CatalystVR) の Catalyst 公式アカウントでは、1日1回、運営が I'm Feeling Lucky を使ってランダムに選ばれたコンテンツを投稿しています。
